# Сашка молодец

Расширяемая двуязычная обучающая PWA для ребёнка: **Deutsch + українська**.

Первый режим: ребёнок слышит и видит «Wo ist die Tomate? / Де помідор?» и выбирает из 2, 4 или 6 картинок. Если ошибся, приложение называет выбранный объект и даёт следующую подсказку.

## Уже реализовано

- 10 категорий, 89 учебных объектов;
- немецкий + украинский;
- 5 уровней сложности;
- адаптивное повторение слабых слов;
- мягкие подсказки после ошибок;
- локальный прогресс;
- режим родителя по долгому нажатию на логотип;
- PWA, полноэкранный режим, Wake Lock, offline shell;
- единый AI-слой для Google Gemini API и OpenAI API;
- API-ключи только на сервере;
- batch-генерация изображений и голосов;
- бесплатный fallback озвучки через SpeechSynthesis браузера.

## Запуск

Нужен Node.js 20+.

```bash
node server.mjs
```

Открыть `http://localhost:4173`.

Прототип не имеет npm-зависимостей.

## Google / OpenAI

```bash
cp .env.example .env
```

Добавить один или оба ключа:

```env
GEMINI_API_KEY=...
OPENAI_API_KEY=...
```

Проверка конфигурации: `GET /api/health`.

## Генерация ассетов

Безопасная проба без API-вызовов:

```bash
node scripts/generate-assets.mjs --dry-run --limit=5
```

5 картинок через Google:

```bash
node scripts/generate-assets.mjs --provider=google --limit=5
```

5 картинок через OpenAI:

```bash
node scripts/generate-assets.mjs --provider=openai --limit=5
```

Озвучка:

```bash
node scripts/generate-assets.mjs --provider=google --audio --audio-only --limit=10
```

## Главный принцип

**AI — автор контента, а не live-воспитатель ребёнка.**

Картинки и качественную озвучку генерируем заранее и одобряем. Игровая логика остаётся предсказуемой, быстрой, дешёвой и способной работать офлайн.

Подробнее: `docs/ARCHITECTURE.md`.

## Как не дать ребёнку выйти на Android

Сайт сам не может отключить Home/переключение приложений. Рабочая схема: установить PWA → запустить её как приложение → включить системное **App pinning / Закрепление приложения** → выход защищается PIN/паролем устройства.

Подробнее: `docs/PWA_KIOSK.md`.
