# Roadmap

## Phase 0 — готово в прототипе
Browser MVP, 89 объектов, 10 категорий, 5 уровней, PWA, прогресс, Google/OpenAI provider layer, batch generator.

## Phase 1 — дать ребёнку 3–5 сессий
Смотреть: понимает ли интерфейс, не малы ли 6 карточек, нравится ли голос, нужен ли второй язык всегда, когда теряется внимание, какие подсказки реально помогают.

## Phase 2 — production content
Сгенерировать единый набор картинок, вручную одобрить, сгенерировать DE/UA-аудио, добавить audio cache и content schema validation.

## Phase 3 — новые механики
Counting, matching, memory, sorting, listening-only, animal sounds, verbs, sizes, sequences.

## Phase 4 — parent dashboard
PIN, профили, статистика, длина сессии, расписание, content studio, AI review queue.

## Phase 5 — platform
Новые языки, content packs, cloud sync, Android wrapper/kiosk при необходимости.

## Не делать рано
Аккаунты, подписки, тяжёлый backend, live AI-chat с ребёнком, генерацию картинки на каждый вопрос и рекламную геймификацию.
