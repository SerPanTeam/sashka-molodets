# Планшет и защита от выхода

## Браузер может

PWA без адресной строки, Fullscreen API, Wake Lock, минимальная навигация и offline cache.

## Браузер не может

Надёжно отключить Home, системный Back, переключение приложений и системный PIN. Это намеренное ограничение безопасности платформы.

## Android — рекомендуемый вариант

1. Открыть в Chrome.
2. Установить PWA / Add to Home screen.
3. Запустить как отдельное приложение.
4. Включить Android App pinning / «Закрепление приложения».
5. Закрепить «Сашка молодец».
6. Включить запрос PIN/пароля при откреплении.

Для отдельного детского устройства позже возможен настоящий Android kiosk/MDM/native wrapper.
