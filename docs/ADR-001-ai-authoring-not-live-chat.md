# ADR-001 — AI authoring, not child live chat
Status: accepted.

Основной игровой цикл детерминирован. Генеративные модели используются для пакетной подготовки изображений/голоса, родительской content studio и контролируемого TTS fallback. Это быстрее, стабильнее, дешевле, безопаснее и позволяет офлайн-режим.
